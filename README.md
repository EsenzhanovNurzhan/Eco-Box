# Eco-Box — обмен вещами вместо выбрасывания 📦🌱

**Eco-Box** — экологический сервис обмена вещами для студенческого сообщества. Проект объединяет физическую точку обмена «Отдай — возьми» с цифровой витриной, чтобы одежда, книги, канцелярия и посуда находили новых владельцев вместо того, чтобы отправляться на свалку.

> Сейчас в репозитории находится frontend-прототип. Физические шкафы, реальные объявления, API, серверная регистрация и начисление баллов пока не подключены.

## Цель проекта

EcoBox — платформа для обмена вещами в студенческой среде. Цифровая платформа помогает находить точки обмена, публиковать вещи и бронировать находки.

- **Обмен вещами:** опубликовать вещь, которую отдаёшь, или найти нужный предмет.
- **Локации:** корпуса и филиалы показываются в каталоге; размещение точек обмена должно быть подтверждено.
- **Студенческая регистрация:** проверка и подтверждение академической почты.
- **Эко-карма:** за участие начисляются баллы и предлагаются награды.

## Возможности прототипа

- Каталог вещей с поиском и фильтрами по категории, состоянию и сроку нахождения в шкафу.
- Выбор корпуса или филиала из списка.
- Интерактивная карта 2GIS MapGL в модальном окне.
- Избранное, экран профиля Эко-кармы и FAQ.
- Бронирование на 20 минут с таймером, отменой и хранением в `localStorage`.
- Экран регистрации на `/signup` с проверкой домена и демонстрационным кодом.
- Интерфейс на русском, казахском и английском; выбранный язык сохраняется в браузере.

Все объявления, баллы и брони в этой версии — демо. Регистрация не создаёт серверный аккаунт и не отправляет письмо.

## Текущий стек

- **Frontend:** Next.js App Router, React, TypeScript, Tailwind CSS, Lucide.
- **Карта:** 2GIS MapGL JavaScript SDK.
- **Хранение состояния:** React state и `localStorage`.
- **Backend:** пока отсутствует.

### Планируемая архитектура

- Django для ORM, администрирования и управления моделями.
- FastAPI для API.
- PostgreSQL как основная БД.
- Redis и Celery для кэша и фоновых задач.
- Aiogram для Telegram-бота.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```powershell
npm install
npm run dev
```

Откройте `http://localhost:3000`. Проверка production-сборки:

```powershell
npm run lint
npm run build
npm run start
```

### Ключ карты 2GIS

Чтобы включить MapGL, скопируйте `.env.example` в `.env.local`, укажите публичный ключ 2GIS в `NEXT_PUBLIC_2GIS_MAPGL_KEY` и перезапустите dev-сервер.

Ключ попадёт в браузерный bundle: ограничьте его разрешёнными доменами и квотами в кабинете 2GIS. Не используйте серверные секреты. `.env.local` исключён из git.

Если Node.js установлен через WinGet и команда `npm` не находится в PowerShell:

```powershell
$nodeDir = (Get-ChildItem "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\OpenJS.NodeJS.LTS*" -Recurse -Filter node.exe | Select-Object -First 1).DirectoryName
$env:PATH = "$nodeDir;$env:PATH"
```
