# EcoBox — обмен вещами вместо выбрасывания 📦🌱

**EcoBox** — экологический сервис обмена вещами для студенческого сообщества. Проект объединяет физическую точку обмена «Отдай — возьми» с цифровой витриной, чтобы одежда, книги, канцелярия и посуда находили новых владельцев вместо того, чтобы отправляться на свалку.

> Сейчас в репозитории находится frontend-прототип. Физические шкафы, реальные объявления, API, серверная регистрация и начисление баллов пока не подключены.

## Цель проекта

EcoBox задуман для университетской среды Атырауского университета нефти и газа имени Сафи Утебаева (AOGU). Цифровая платформа должна помогать студентам находить точки обмена, публиковать вещи и бронировать находки.

- **Обмен вещами:** студент публикует вещь, которую отдаёт, или ищет нужный предмет.
- **Локации AOGU:** корпуса и филиалы показываются в каталоге; точное размещение EcoBox должно быть подтверждено университетом.
- **Студенческая регистрация:** целевой сценарий включает проверку и подтверждение академической почты.
- **Эко-карма:** за подтверждённое участие планируется начислять баллы и предлагать награды.

## Возможности прототипа

- Каталог демонстрационных вещей с поиском и фильтрами по категории, состоянию и сроку нахождения в шкафу.
- Выбор корпуса или филиала AOGU из демонстрационного списка, составленного по данным 2GIS.
- Интерактивная карта 2GIS MapGL в модальном окне. Для корпуса №2 используется точка из предоставленной ссылки; для остальных корпусов точные координаты не заданы.
- Избранное, экран профиля Эко-кармы и FAQ.
- Демо-бронирование на 20 минут с таймером, отменой и хранением в `localStorage` текущего браузера.
- Демо-экран регистрации на `/signup` с проверкой домена `aogu.edu.kz` и демонстрационным кодом `246810`.
- Интерфейс на русском, казахском и английском; выбранный язык сохраняется в браузере.

Все объявления, баллы и брони в демо — тестовые. Регистрация не создаёт серверный аккаунт и не отправляет письмо. Демо-код виден в интерфейсе и не предназначен для production.

## Текущий стек

- **Frontend:** Next.js App Router, React, TypeScript, Tailwind CSS, Lucide.
- **Карта:** 2GIS MapGL JavaScript SDK.
- **Хранение демо-состояния:** React state и `localStorage`.
- **Backend:** пока отсутствует.

### Целевая архитектура

Планируемый backend: Django для ORM, администрирования и управления доменной моделью; FastAPI для API; PostgreSQL как основная база; Redis и Celery для кэша и фоновых задач; Aiogram для Telegram-бота. Этот стек описывает направление развития, а не текущие зависимости приложения.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```powershell
npm install
npm run dev
```

Откройте `http://localhost:3000`. Проверка production-сборки:

```powershell
npm run lint
npm run build
npm run start
```

### Ключ карты 2GIS

Чтобы включить MapGL, скопируйте `.env.example` в `.env.local`, укажите публичный ключ разработчика 2GIS в `NEXT_PUBLIC_2GIS_MAPGL_KEY` и перезапустите dev-сервер. Без ключа карта показывает безопасное fallback-состояние и ссылку на выбранную точку 2GIS.

Ключ `NEXT_PUBLIC_*` попадёт в браузерный bundle: ограничьте его разрешёнными доменами и квотами в кабинете 2GIS. Не используйте здесь серверные секреты. `.env.local` исключён из git.

Если Node.js установлен через WinGet и команда `npm` не находится в PowerShell, добавьте каталог Node.js в PATH текущего терминала:

```powershell
$nodeDir = (Get-ChildItem "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\OpenJS.NodeJS.LTS*" -Recurse -Filter node.exe | Select-Object -First 1).DirectoryName
$env:PATH = "$nodeDir;$env:PATH"
```
